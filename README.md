# Netflix Titles Dataset — Exploratory Data Analysis

## Project Overview

This project focuses on exploring and analyzing the Netflix Titles dataset to understand content distribution, release trends, popular genres, and country-wise content availability.

The project follows a structured data science workflow that includes data understanding, data cleaning, feature engineering, exploratory data analysis, data visualization, and basic trend prediction using Python.

## Project Objectives

- Understand the structure and characteristics of the Netflix Titles dataset.
- Clean missing values, remove duplicate records, and prepare data for analysis.
- Perform feature engineering to derive useful analytical features.
- Analyze the distribution of Movies and TV Shows.
- Explore content release trends over time.
- Identify the most common genres and countries represented in the dataset.
- Generate visualizations to communicate analytical findings.
- Explore potential future content trends using a basic prediction approach.

## Dataset Information

The project uses the Netflix Titles dataset, which contains information about movies and TV shows available on Netflix.

Key columns include:

- `show_id` — Unique identifier for each title.
- `type` — Content type, such as Movie or TV Show.
- `title` — Name of the title.
- `director` — Director or directors associated with the title.
- `cast` — Cast members.
- `country` — Country or countries associated with the title.
- `date_added` — Date the title was added to Netflix.
- `release_year` — Original release year.
- `rating` — Content rating.
- `duration` — Movie runtime or number of TV show seasons.
- `listed_in` — Genres or categories associated with the title.
- `description` — Short description of the title.

## Data Processing Workflow

### 1. Data Understanding

- Load the raw dataset.
- Inspect the dataset dimensions, column names, data types, and sample records.
- Examine missing values and duplicate records.
- Review the dataset structure before cleaning.

### 2. Data Cleaning

- Remove duplicate records.
- Handle missing values in relevant columns.
- Convert `date_added` into a datetime format.
- Standardize text fields where appropriate.
- Save the cleaned dataset for subsequent processing.

### 3. Feature Engineering

- Create `release_decade` to group titles by release decade.
- Create `is_movie` to identify movie records.
- Create `content_type` to standardize content-type labels.
- Extract `added_year` from `date_added`.
- Prepare derived features for exploratory analysis.

### 4. Exploratory Data Analysis

Analyze the processed dataset to identify patterns in content types, release years, genres, and countries. Use appropriate aggregation methods and visualizations to communicate the findings.

## Visualizations

The project generates five visualizations, stored in the `outputs/` directory:

1. **Movie vs TV Show Distribution** — Compares the proportions of Movies and TV Shows.
2. **Content Released Per Year** — Illustrates the distribution of titles by release year.
3. **Top 10 Genres** — Highlights the most frequently represented genres.
4. **Country-wise Content Distribution** — Examines content representation across countries.
5. **Netflix Content Trend Prediction** — Presents a basic projection of potential content trends.

The visualization files are generated by the exploratory data analysis module and can be reviewed directly in the `outputs/` directory.
